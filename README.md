# 스위치 2 《젤다의 전설: 시간의 오카리나 (2026)》 100% 인터랙티브 공략집

닌텐도 스위치 2 풀 리메이크작 **《젤다의 전설: 시간의 오카리나 (2026)》**의 메인 스토리·전 던전 진행부터 100% 수집 요소 달성까지 관리할 수 있는 웹 공략 아카이브입니다.

## 주요 기능

- **🗡️ 메인 스토리 & 던전 공략 (제1장 ~ 제14장)**
  - 소년기(데크나무님 속, 도동고의 동굴, 자부자부님 뱃속, 우물 바닥) 및 청년기(숲·불·물의 신전, 얼음 동굴, 어둠·영혼의 신전, 겔드의 수련장, 가논의 성) 전 구간 단계별 체크리스트
  - 스위치 2 리메이크(2026) 변경점 배지 및 **패배한 적의 전당(보스 리매치)** 타임어택 공략 팁 수록
- **🕷️ 100% 수집 요소 체크리스트 (`localStorage` 자동 저장 & JSON 백업)**
  - **황금 스탈튤라 100마리** 전체 번호별·지역별·시대별 입수 조건 및 스탈튤라의 집 보상 트래커
  - **하트 조각 36개** 전체 위치 및 미니게임 변경 사항 정리
  - **핵심 서브 퀘스트 & 업그레이드**: 빈 병 4개, 행복의 가면 거래(진실의 가면 독심술 포함), 빅고론도(대장군검) 물물교환 10단계, 대요정의 샘 6곳, 스위치 2 신규 아이템(메아리 돌, 장사꾼 데크 씨앗)
- **🎵 오카리나 악보 & Web Audio API 실시간 연주 스튜디오**
  - 정규 12곡 + 특수 악보(허수아비의 노래, 개구리 합창단) 스위치 2 버튼 표기
  - 외부 음원 없이 브라우저 내장 Web Audio API로 실제 오카리나 5음계(D Dorian) 멜로디 미리듣기 및 직접 연주/자동 곡 인식 기능
- **🔍 통합 검색 & 다중 필터링**
  - 실시간 키워드 검색(`Ctrl+K`), 시대(`소년기`/`청년기`), 지역/던전, 획득 상태(`미획득만`/`획득 완료`) 즉시 필터링

## 로컬 실행 방법

별도의 빌드 과정 없이 정적 웹 서버로 바로 실행할 수 있습니다.

```bash
python3 -m http.server 8080
```
이후 브라우저에서 `http://localhost:8080`에 접속합니다.
